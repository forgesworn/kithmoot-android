# Native invitation controls

Confirmed retirement and exact-original resend use public binding, source
revision, epoch, lifecycle and foreground owner generation only as expectations.
The actual serialized controller/source still verifies authority and current
receiver state before unsigned preflight, signing or reservations. No legacy
raw host key or fresh retry budget is introduced. Cancel and stale owners refuse.

Native cold room state starts without a URL. Only actual Ready/ACTIVE restores
sharing; retired/pending/failed/suspended/closed observations withdraw it. Every
live open/copy/share callback also uses a nonblocking actual source guard.
QR sheets close when availability changes, and native open flags do not survive
another foreground owner/visit/process. Home reads a native host's actual source
under its exclusive lease on IO rather than trusting a stale saved retired flag.
A handed-out link or clipboard copy cannot be revoked by hiding controls.

The retired saved-room hint is repaired only after a source-derived observation,
with exact invitation/reference preserved. Failed hint repair cannot restore the
URL or source. Both approval projections check current hosting availability;
a late older participant list cannot revive retired or unavailable cards.
Approved existing devices keep their epoch, current recovery and paired chat.

Design mesh-kit fbef5e2 precedes these controls; approval ordering is refined in
915aa33 before its correction. Nine rendered host cases retain all six existing
journeys and add Nearby/Mixed retirement/reopen/resend plus open-QR withdrawal.
The final integrated head must pass its own four hosted jobs, every retained
member/PID gate and main's actual repeated-Send acceptance before merge.
Local source compilation is not installed Android or physical radio evidence.

Replacement, pending-recovery controls, terminal controls/migration,
retirement-specific SIGKILL windows and propagation to every participant client
remain separate work. This host increment does not prove joint store/key rollback
resistance or real BLE/radio/group/UK-Portugal operation. No radio settings,
firmware, public relay or group backhaul changes are made here.
